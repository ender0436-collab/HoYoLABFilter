# HoYoLAB Filter

HoYoLAB の投稿を、NGワード・NGユーザー・NGタグで非表示にできる Chrome 拡張機能です。

## 主な機能

- ⛔ 投稿者名横からワンクリックでNGユーザー登録
- ⛔ タグ横からワンクリックでNGタグ登録
- 📝 NGワードによる投稿非表示
- 📦 設定のインポート / エクスポート

## インストール方法

1. GitHubの **Code** → **Download ZIP** を選択してダウンロードします。
2. ダウンロードしたZIPファイルを展開します。
3. Chromeで `chrome://extensions/` を開きます。
4. 画面右上の **デベロッパーモード** をオンにします。
5. 左上の **パッケージ化されていない拡張機能を読み込む** をクリックします。
6. 展開したフォルダー **HoYoLABFilter-main** を選択します。

## 使い方

### NGユーザーの登録

投稿者名の横に表示される⛔ボタンをクリックすると、そのユーザーをNG登録できます。

### NGタグの登録

タグ横に表示される⛔ボタンをクリックすると、そのタグをNG登録できます。

### 設定画面を開く

1. Chromeツールバーの拡張機能アイコンをクリックします。
2. **HoYoLAB Filter** を選択します。
3. **設定** をクリックします。

### 設定画面でできること

- NGワード追加・削除
- NGユーザー追加・削除
- NGタグ追加・削除
- CSVファイルのインポート
- CSVファイルのエクスポート  
※設定画面はダークモードにできます。

## 注意事項

- 本拡張機能は投稿を削除するものではありません。
- 投稿は利用者のブラウザ内でのみ非表示になります。
- HoYoLAB の仕様変更により一部機能が動作しなくなる場合があります。
- 本拡張機能は HoYoverse および HoYoLAB とは提携していません。

## 保存されるデータ以下の設定のみ保存されます。

- NGワード一覧
- NGユーザーID一覧
- NGタグ一覧
- ダークモード設定

投稿内容や個人情報は保存されません。
